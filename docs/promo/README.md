# 推广素材

三个平台的发帖模板，都写成了**可以整段复制的草稿**（`⟨…⟩` 是待填的）。

| 平台 | 文件 | 面向谁 | 语气 |
| --- | --- | --- | --- |
| V2EX（分享创造） | [`v2ex.md`](v2ex.md) | 中文技术社区 | 直给，先说痛点再说「所以这轮加了什么」 |
| 少数派 | [`sspai.md`](sspai.md) | 中文用户 | 长文，讲「你用起来什么感觉」 |
| Show HN | [`show-hn.md`](show-hn.md) | 英文技术社区 | 极短，设计取舍 + 明确的「做不到什么」 |

## 三个平台共用的红线

1. **不删「已知局限」那一段**。三个模板里都留了它，删掉就变成另一种文章了 —— 而且评论
   一定会问，你提前答了就是加分。
2. **不用**「AI」「一站式」「重新定义」「海量」「秒杀」。
3. **35 条 Recipe 就叫 35 条**，别写「几十条」「大量」。
4. **没验证过的事不许说**。特别是：zsh 集成没有真机实测；多架构 Release 没真发过；
   featured Recipe 没有逐条手工跑过。这些在仓库里都写着，帖子里保持一致。
5. **截图必须是真的**（用真终端跑真命令），不要用示意图代替。

## 截图清单（一次拍完，三个平台都能用）

| 编号 | 画面 | 放在哪 | 要能看出什么 |
| --- | --- | --- | --- |
| 1 | 主界面（域标签 + 工具列表 + 右侧说明） | 三个平台都用 | 这不是文件管理器，是「工具 + 分类」 |
| 2 | 一个表单填参数的过程（ffmpeg 转码最佳） | 三个平台都用 | 「填表」到底省了什么 |
| 3 | `Ctrl-G` 选择器，**下面一行还能看到 shell prompt** | 三个平台都用 | 命令是被回填到输入行，不是直接执行 |
| 4 | `F` 视图 + 视频缩略图（面板标题写着「视频缩略图」） | 少数派、V2EX | 缩略图这件事真的做了 |
| 5 | `history list` 或输出历史回看 | 少数派 | 「可回看」不是口号 |
| 6 | `toolbox-hub widget fish | source` 在 fish 里跑通的终端 | 可选 | 三个 shell 都支持（zsh 除外，别混进去） |

拍摄注意：终端主题统一（深色）、字号够大、截完把用户名/主机名/隐私路径修掉。
`Ctrl-G` 那张最好能拍到**上一行是刚执行的命令**，比空 prompt 有说服力。

## 发布顺序建议

先 Show HN / V2EX 看反应（技术社区会挑出真问题），把评论里暴露出的坑修掉、写进
「已知局限」，再发少数派那种用户向长文。倒过来的话，长文里承诺的东西会被技术社区
当场打脸，改起来更贵。
