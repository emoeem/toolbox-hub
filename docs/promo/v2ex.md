**标题**：[分享创造] 把一堆 CLI 工具包成可填表的 TUI，顺手给 shell 加了个 Ctrl-G 命令选择器

**正文**：

写这个的起因很土：我记不住 `ffmpeg` 抽音轨那串参数，也不记得自己那两个脚本叫什么名字。
于是一开始只是想做个「表单生成器」，后来越加越多，现在它已经是我开机就在跑的东西。

**它是什么**：一个 Rust 写的 Linux TUI 工具箱。左边是工具列表（内置动作 + 你自己丢进去的脚本 +
远程工具包），选中按回车弹出表单，参数填完执行，输出留在历史里。**它不是启动器**：GUI 只是 CLI 的
交互层，真正干活的还是命令行工具本身。同一个二进制也是命令行工具（`toolbox-hub -s fzf` 之类）。

这轮新加的东西，挑几个我觉得真有用的：

**1. `Ctrl-G` 命令选择器（shell 集成）**

```bash
eval "$(toolbox-hub widget bash)"   # zsh 换 widget zsh；fish 用 | source
```

按 `Ctrl-G` 弹出选择器，选中的命令**填到你正在输入的这一行**，回车前还能改。执行和写历史都是
shell 自己干的 —— 所以历史里存的是 `uname -r`，不是什么 `toolbox-hub widget …`。

**2. 35 条精选 Recipe + 三种速查格式导入**

`import navi|cheat|tldr <文件>` 能把现成的速查表转成可填表的 Recipe。有意思的是它**不全转**：
管道、重定向、命令替换一律只标记成「仅展示」——从字符串还原 shell 语义必然出错，不如老实说
「这条你得自己看」。有 `--dry-run` 先看它打算怎么处理。

**3. 视频预览有缩略图了**

以前 `F` 视图选中 mp4 就是一片空白。现在会调 ffmpeg 抓第一帧，**并且落盘缓存**，翻来翻去不会
反复起 ffmpeg。缓存键带了文件体积和 mtime —— 只按路径做键的话，同名文件换了内容，屏幕上还是
旧画面，这个坑我踩过。

**4. 危险动作分三级**

`safe` / `caution` / `destructive`。破坏性的默认拦着，要 `--confirm-destructive` + 一段
`--audit` 说明 + 环境变量三个都齐才放行。判定是**规则式黑名单**（`rm -fr`、`dd of=`、`| bash`、
`sudo` 这些），我在 README 里把「拦不住什么」也列了：`xargs rm -rf`、`find -delete`、别名、
脚本内部的动作 —— 它不是沙箱，只是第一道闸。

**已知局限**（我写在仓库里的原文）：

- 没真的发过 Release，多架构产物只在本地验过打包与签名逻辑；
- zsh 的集成脚本生成了但没在真 zsh 里按过键（我机器上没装 zsh）；
- 队列是串行后台任务，取消只有 API，没有交互式入口；
- 非 Arch 要 `--no-default-features` 构建核心版（不链接 libalpm），包管理域不可用。

**仓库**：⟨GitHub 地址⟩（MIT）

构建：`cargo build --release`（Arch 默认带包管理，链接 libalpm）；非 Arch 加 `--no-default-features`。

有想法直接说，尤其是「这个功能为什么多余」那种。

## 配图建议

1. 主界面（工具列表 + 域标签）—— 一眼看出「这不是文件管理器」；
2. 一个表单的填写过程（比如 ffmpeg 转码）—— 最能说明卖点；
3. `Ctrl-G` 选择器回填到输入行的截图（终端里能看到上一行还是普通 prompt）；
4. `F` 视图 + 视频缩略图。
